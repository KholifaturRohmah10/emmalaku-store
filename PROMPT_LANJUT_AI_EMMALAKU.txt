1. Identitas proyek

Nama proyek: EMMALAKU
Lokasi lokal: C:\xampp\htdocs\emmalaku
Jenis proyek: Web app Laravel + Blade + Vite + JavaScript.
Konsep tampilan: aplikasi food order mobile-first dengan versi desktop/PC responsive.

Ini bukan aplikasi Android/iOS native.
Ini web app yang desainnya dibuat terasa seperti aplikasi mobile dan sudah ditambah mode PC.

7. Catatan deploy Vercel yang sangat penting

Project ini akhirnya dideploy ke Vercel sebagai STATIC STOREFRONT.
Alasannya:
- Laravel serverless PHP di Vercel sempat error 500 berkali-kali.
- Error yang pernah muncul: service provider Laravel seperti view, view.finder, translator bermasalah di runtime Vercel.
- Aplikasi ini tidak membutuhkan database server untuk bisnis logic.
- Semua interaksi utama berjalan di JavaScript/localStorage.

Konfigurasi Vercel:
- vercel.json memakai outputDirectory: public
- installCommand dibuat echo saja
- buildCommand dibuat echo saja
- Vercel tidak boleh menjalankan npm run build otomatis, karena HTML static dan asset hash bisa tidak sinkron.

Jika mengubah CSS/JS/Blade:
1. Jalankan npm build.
2. Jalankan export static.
3. Commit semua perubahan public hasil export.
4. Push ke GitHub.

Perintah wajib setelah perubahan frontend:
npm.cmd run build
php scripts/export-static.php

Lalu cek:
- public/build/manifest.json
- HTML di public sudah memanggil CSS/JS hash terbaru
- public/build/assets berisi file CSS/JS yang dipanggil HTML

Contoh cek lokal static:
php -S 127.0.0.1:8099 -t public
Buka:
http://127.0.0.1:8099/beranda
http://127.0.0.1:8099/produk
http://127.0.0.1:8099/produk/pepperoni-pizza

9. Cara menjalankan lokal sebagai Laravel

Masuk folder:
cd C:\xampp\htdocs\emmalaku

Install dependency jika belum ada:
composer install
npm install

Jalankan Laravel:
php artisan serve

Jalankan Vite untuk development:
npm run dev

Buka:
http://127.0.0.1:8000

14. Ringkasan paling penting

EMMALAKU sekarang adalah Laravel untuk development lokal, tetapi Vercel production memakai static export dari folder public.
Setiap perubahan UI harus diikuti:
npm.cmd run build
php scripts/export-static.php
git add resources public ...
git commit
git push origin main

Jangan biarkan Vercel build ulang asset, karena bisa membuat HTML memanggil CSS lama dan tampilan menjadi amburadul.
